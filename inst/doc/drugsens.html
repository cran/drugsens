Get Started with drugsens

5-Minute Quickstart

drugsens automates the processing, quality control, control normalization, and dose-response visualization of single-cell fluorescence microscopy data exported from QuPath, following the protocol in Labrosse et al. (2024) (doi:10.1016/j.xpro.2024.103274).

1. Import and Bind QuPath CSV Exports

library(drugsens)

example_dir <- system.file("extdata/to_merge/", package = "drugsens")
bind_data <- data_binding(
  path_to_the_projects_folder = example_dir,
  files_extension_to_look_for = "csv"
)

3. Inspect Quality Control (QC) Distributions

Plot per-marker positivity distributions for a single patient (get_QC_plots()):

get_QC_plots(
  long_df,
  isolate_a_specific_patient = "B39",
  x_plot_var = "Treatment",
  compare_to_control = TRUE,
  save_plots = FALSE
)

Or inspect marker positivity across treatments for a patient (get_QC_plots_parsed_merged_data()):

qc_list <- get_QC_plots_parsed_merged_data(
  long_df,
  list_of_columns_to_plot = "marker_positivity_ratio",
  fill_color_variable = "Treatment_complete",
  isolate_specific_patient = "B38",
  save_plots = FALSE,
  verbose = FALSE
)

qc_list[["B38.marker_positivity_ratio"]]

4. Normalize Target Cell Viability to Control & Fit Dose-Response

Select your dead/dying marker(s) (dead_markers) and viable cancer marker(s) (viable_markers) in normalize_to_control() to compute target cancer cell viability relative to Control (100%):

norm_df <- normalize_to_control(
  long_df,
  dead_markers = c("cCASP3", "E-Cadherin and cCASP3"),
  viable_markers = "E-Cadherin",
  control_treatment_name = "Control",
  consensus_only = TRUE
)

plot_treatment_summary(norm_df, compare_to_control = TRUE)
